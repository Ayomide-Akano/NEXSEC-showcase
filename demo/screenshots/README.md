# Sanitized screenshots

Place selected screenshots from the NEXSEC lab here.

Before publishing any screenshot, replace or blur:

- real IP addresses;
- MAC addresses;
- hostnames;
- usernames or email addresses;
- credentials, tokens, keys, cookies, or session identifiers;
- private filesystem paths;
- internal database details;
- other information that could identify a private environment.

Use documentation values such as `10.0.0.x` where appropriate.
